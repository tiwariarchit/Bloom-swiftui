# Bloom 🌱

Bloom is a SwiftUI-based iOS application focused on helping users build healthier habits through progress tracking, mindfulness, breathing exercises, and short guided interventions.

## Features

- Progress and streak tracking
- Statistics and weekly progress
- Guided meditation and breathing exercises
- Urge-delay and grounding exercises
- Quick reset activities
- AR-based Keep Away experience using face tracking
- Audio cues for guided exercises

## Tech Stack

- Swift
- SwiftUI
- ARKit
- Xcode
- iOS 16+

## Project Structure

The main Xcode project is `quit_porn.xcodeproj`. The Swift source files and assets are located in the `quit_porn/` directory.

## Getting Started

1. Clone this repository.
2. Open `quit_porn.xcodeproj` in Xcode.
3. Select an iPhone Simulator or connected iPhone.
4. Build and run the app.

### AR Feature

The AR Keep Away experience requires a device that supports AR face tracking and appropriate camera permission. It may not work in the iOS Simulator.

## Privacy

This project is intended as a personal/student software project. Review the app's permissions and data handling before using it with real personal data.
